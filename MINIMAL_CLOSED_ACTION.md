# Минимальное замкнутое действие Pippa

## 1. Что именно выводится

Это низкоэнергетическое четырёхмерное замыкание фазового сектора. Оно
предполагает, что радиальные амплитуды четырёх информационных конденсатов уже
стабилизированы, а внутренняя дробная координата находится в своей нулевой
моде.

Дополнительные предположения:

1. Общая диагональная фазовая симметрия является глобальной, а не
   калибровочной. Иначе общая фаза была бы нефизической.
2. Обычная материя и информационные поля минимально связаны с одной метрикой.
3. Прямой внешний источник `M[A(x)]` отсутствует.
4. Относительные фазы связаны положительным потенциалом графа `Z2 x Z2`.

Пункты 1-4 являются постулатами минимального замыкания. Формулы ниже являются
их следствиями.

## 2. Действие

Для фаз

```text
theta = (theta_N, theta_Neg, theta_Mir, theta_NegMir)
```

принимается

```text
S_min = integral d^4x sqrt(-g) [
          M_*^2 R/2
        + L_SM(g, matter)
        - f^2/2 sum_g nabla_mu(theta_g) nabla^mu(theta_g)
        - V_lock(theta)
        - V_DE(theta)
        ].
```

Потенциал относительных фаз:

```text
V_lock = sum_(g<h) kappa_gh [1-cos(theta_g-theta_h)].
```

Он точно сохраняет общий сдвиг

```text
theta_g -> theta_g + alpha.
```

Нормированная общая координата равна

```text
q_0 = (theta_N + theta_Neg + theta_Mir + theta_NegMir)/2.
```

Мягкое явное нарушение общей симметрии:

```text
V_DE = Lambda^4 [1-cos(q_0)].
```

При `Lambda -> 0` точная симметрия восстанавливается. Поэтому малая масса
общей моды технически защищена.

## 3. Спектр

Гессиан `V_lock` около выровненного вакуума является лапласианом секторного
графа. В character-базисе `Z2 x Z2` массы диагональны:

```text
m_0^2      = Lambda^4/f^2,

m_Neg^2    = 2(kappa_Neg + kappa_NegMir)/f^2,
m_Mir^2    = 2(kappa_Mir + kappa_NegMir)/f^2,
m_NegMir^2 = 2(kappa_Neg + kappa_Mir)/f^2.
```

При положительных `kappa` три относительные моды не тахионны. При
`Lambda=0` общая мода точно безмассовая без сокращения независимых больших
чисел.

Общая мода является кандидатом на тёмную энергию. Три относительные моды
могут быть кандидатами на тёмную материю, но только при дополнительных
динамических условиях из раздела 7.

## 4. Уравнения движения и сохранение

Вариация фаз даёт

```text
f^2 box(theta_g) - partial V/partial theta_g = 0.
```

Тензор энергии-импульса информационного сектора:

```text
T_I(mu,nu) =
    f^2 sum_g partial_mu(theta_g) partial_nu(theta_g)
    + g_mu_nu L_I.
```

Уравнение метрики:

```text
M_*^2 G_mu_nu = T_SM(mu,nu) + T_I(mu,nu).
```

Поскольку действие диффеоморфно-инвариантно и прямой зависимости
`V(theta,A)` нет, на уравнениях движения

```text
nabla_mu T_SM^(mu,nu) = 0,
nabla_mu T_I^(mu,nu)  = 0.
```

Полный закон сохранения замкнут. Внешний изменяющийся `A(x)` снова нарушил бы
это свойство, если не добавить обратное воздействие на материю.

## 5. Локальный тензор для сферического состояния

Обозначим

```text
K_t = f^2/2 sum_g dot(theta_g)^2,
K_r = f^2/2 sum_g theta'_g^2.
```

Тогда в локальном ортонормированном базисе

```text
rho = K_t + K_r + V,
p_r = K_t + K_r - V,
p_t = K_t - K_r - V.
```

Статическая пространственная структура обычно имеет `p_r != p_t`.
Следовательно, произвольный профиль фазы нельзя просто объявить плотностью
холодной тёмной материи.

## 6. Слабое поле и линзирование

Для метрики

```text
ds^2 = -(1+2 Phi)dt^2 + (1-2 Psi)dx^2
```

статические линеаризованные уравнения Эйнштейна дают

```text
laplacian(Psi) = 4 pi G rho,

laplacian(Phi) = 4 pi G (rho + p_r + 2p_t).
```

Нерелятивистские орбиты измеряют `Phi`, а свет чувствителен к
`(Phi+Psi)/2`. Поэтому три эффективных источника равны

```text
rho_curvature = rho,

rho_dynamics  = rho + p_r + 2p_t,

rho_lensing   = rho + (p_r + 2p_t)/2.
```

При `p_r=p_t=0` все три массы совпадают. Тогда одна и та же конфигурация
объясняет движение тел и линзирование без отдельной подгоночной
«гравитационной массы».

## 7. Когда относительная мода становится холодной материей

Рассмотрим малую относительную character-моду

```text
q_chi(t,r) = Q(r) cos(m_chi t).
```

После усреднения по быстрым осцилляциям:

```text
<K_t> = <V> = f^2 m_chi^2 Q^2/4,
<K_r>       = f^2 (Q')^2/4.
```

Введём

```text
epsilon_grad = (Q'/(m_chi Q))^2.
```

Тогда

```text
rho_dynamics = f^2 m_chi^2 Q^2/2,

rho_lensing/rho_dynamics = 1 + epsilon_grad/4.
```

Таким образом, при

```text
m_chi/H >> 1,
epsilon_grad << 1
```

относительная мода ведёт себя как холодная тёмная материя, а массы по орбитам
и линзированию совпадают. Кодовый тест, например, получает расхождение ровно
1% при `epsilon_grad=0.04`.

Статический чисто градиентный профиль даёт другой результат:

```text
rho_dynamics = 0,
rho_lensing  = rho/2.
```

Это no-go для непосредственного отождествления старого статического
`M_N[A]` с физической плотностью тёмной материи.

## 8. Общая мода как тёмная энергия

Для выровненных относительных фаз и общей координаты около вершины
`q_0=pi`:

```text
K_t << V,
K_r = 0,
p = -rho,
w = -1.
```

Нормировка

```text
2 Lambda^4 = rho_DE,
|m_0| = H0
```

даёт `f=1.014 M_Pl(reduced)`. Полная FRW-проверка этой моды находится в
`pippa/dark_energy_dynamics.py`.

## 9. Что получилось и что не получилось

Следует из минимального действия:

- одна защищённая общая псевдо-Голдстоуновская мода;
- три устойчивые относительные моды при положительных связях;
- ковариантный сохраняющийся тензор энергии-импульса;
- одинаковая гравитационная масса для орбит и линзирования в холодном
  осциллирующем пределе;
- тёмно-энергетическое состояние общей моды около вершины.

Пока не выведено:

- значения трёх `kappa` и массы относительных мод;
- механизм рождения, стабильность и современная плотность этих мод;
- профиль `Q(r)` конкретной галактики;
- наблюдаемая связь между барионами и профилем относительных мод;
- ультрафиолетовая динамика радиальных полей и межсекторных мостов;
- двумерное линзирование реальных галактик и скоплений.

Минимальное действие поэтому является согласованным кандидатом, но ещё не
полной моделью тёмной материи. Следующий решающий расчёт должен решить
уравнения Эйнштейна-Клейна-Гордона для осциллирующей относительной моды и
одними параметрами сравнить кривую вращения и линзирование.

Реализация находится в `pippa/minimal_closed_action.py`, автоматические
проверки — в `tests/test_minimal_closed_action.py`.
